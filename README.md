# Micro-CPU

Projeto de uma micro-CPU para a disciplina Prática em Sistemas Digitais, código SSC0108, do curso de Ciências de Computação do ICMC-USP.

Abra `projeto.qpf` na raiz para trabalhar na CPU atual. `teste.qpf` contém o teste do LCD, e `Micro_CPU.qpf` mantém a versão anterior para Cyclone V.

Os circuitos ficam em `src/`, as memórias em `memoria/` e o conversor em `ferramentas/`.
